# UI 设计

- 需求编号：`REQ_20260827_hero_every_token_counts`
- 版本号：`v1`

## 1. 设计目标

- 关键词：克制、技术感、可追踪、立体层级、少文字。
- 单页任务：用三幅图让访客快速理解“Token 基础设施 → 决策闭环 → 企业数仓”。
- 视觉签名：每段使用一幅深色“系统切片”插画，蓝、紫、珊瑚三种信号色贯穿三段。
- 参考模式：`reference-only`，不复刻参考页面的 HUD、长文案和 WebGL 交互。

## 2. 视觉基线

| Token | 规则 |
|---|---|
| 页面背景 | 沿用项目 `background` / `foreground` 主题变量 |
| 插画底色 | 深海军蓝 `#07101E`，在明暗主题下保持统一的“技术窗口”观感 |
| 01 主色 | 信号蓝 `#4D8DFF` + 紫 `#A37BFF` + 金 `#F2CF4E` |
| 02 主色 | 电光蓝 `#60A5FA` + 紫 `#A78BFA` + 珊瑚 `#FB8A6A` |
| 03 主色 | 蓝 `#60A5FA` + 紫 `#A78BFA` + 青 `#5EEAD4` + 珊瑚 `#FB8A6A` |
| 标题 | 现有无衬线字体，Hero 按断点使用 `text-4xl` / `text-5xl` / `text-6xl`，分段标题使用 `text-4xl` / `text-5xl`，均为正常字距 |
| 辅助文字 | 现有正文体，单句、最多一行到两行 |
| 圆角 | 插画容器 `0.5rem`，编号使用无底色的纯文本标记 |
| 边框 | `border-border/60`，插画内使用低透明度网格和描边 |
| 动效 | 仅沿用现有首屏淡入；三幅插画不做持续动画，尊重 reduced motion |

## 3. 页面结构

```text
01  短标题 + 一句说明   |  三层业务堆叠图
02  短标题 + 一句说明   |  Token 流收束到成交环
03  短标题 + 一句说明   |  ODS/DWD/DWS/ADS 立体数仓
```

- 桌面端采用文字与插画双栏，02 反向排列形成节奏。
- 移动端统一先文字后插画，避免视觉顺序与阅读顺序冲突。
- 三段编号保留，作为主页叙事顺序，而不是装饰。

## 4. 插画规则

- 01：只保留 `TOKEN / BRAIN / FDE` 三层和最终输出节点，表达从算力到底层业务成果的路径。
- 02：左侧 Token 粒子经过四道收束门，汇成右侧成交环和上升曲线。
- 03：只保留 `ODS / DWD / DWS / ADS` 四层与顶部 AI 决策节点。
- 所有插画使用内联 SVG，必须有可访问名称，不依赖远程图片、字体或脚本。

## 5. 禁用方向

- 不使用长卡片列表、筛选按钮、抽屉详情或大段模块说明。
- 不使用持续闪烁、旋转、漂浮等装饰动画。
- 不把参考图中的文字、指标或尺寸标注直接搬到主页。

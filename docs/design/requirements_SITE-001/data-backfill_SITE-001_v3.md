# 数据回填

- 需求编号：`SITE-001`
- 版本号：`v3`

## 回填目标

- 新表上线前不存在 FDE 预约事实源，因此没有历史记录可以可靠回填。
- 本轮不从旧 demo 表单、日志或浏览器存储构造预约，避免制造不可追溯 PII。

## 回填规则

| 场景 | 回填来源 | 规则 | 风险 |
|---|---|---|---|
| 新表初始数据 | 无 | 空表上线，后续仅由公开预约 API 写入 | 无历史数据 |
| 既有 demo 提交 | 无持久化事实源 | 不回填 | 无法证明提交真实性和授权 |

SQL 交付物 `docs/sql/requirements_SITE-001/data-backfill_SITE-001_v3.sql` 只提供迁移后的空表/数据量核查，不写入业务数据。

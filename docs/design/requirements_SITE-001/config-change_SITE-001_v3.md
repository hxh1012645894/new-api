## 配置变更清单

| 配置项 | 变更前 | 变更后 | 作用环境 | 是否必需 | 备注 |
|---|---|---|---|---|---|
| `OptionMap["Notice"]` 默认值 | 空字符串 | iFAi 三档月规模定价 Markdown | 全部环境 | 是 | 数据库存在非空 Notice 时仍由后台配置覆盖 |
| `VITE_FDE_FORM_ENDPOINT` | 可选；未配置时模拟成功 | 不再使用 | 前端全部环境 | 否 | 表单固定调用同源 `/api/fde/appointments` |

未新增环境变量、密钥、第三方连接或部署凭据。Logo 作为静态资源 `/ifai-logo.png` 随前端包发布，不依赖外部地址。

`Notice` 是由后端配置并可被管理员覆盖的动态运营内容，不属于前端 locale JSON 中的静态 UI 文案。本轮内容直接采用中文定价参考原文，因此不会随界面语言切换；如需多语言公告，应另行扩展按语言存储和读取的配置模型，不能把不同语言硬编码进现有单值 Notice。

## 生效与验证

- 生效方式：部署同版本前后端；后端启动加载默认 Notice，前端直接读取同源 API。
- 是否需要重启：后端 Notice 默认值需要进程重启；前端需要重新构建/发布。
- 验证方式：访问 `/api/notice`，并从首页通知弹层检查定价表；提交 FDE 表单并确认请求指向本站 API。
